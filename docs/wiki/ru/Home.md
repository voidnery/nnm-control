# NNM-Control

[English](../en/Home.md) · Русский

NNM-Control — веб-панель для эксплуатации серверов Nimble Streamer: серверы и их потоки, настройки
потоков в WMSPanel, плейлисты, раздача через свою сеть, LL-HLS, логи и статистика — в одном месте, с
правами доступа, журналом аудита, API и событиями.

## Основные понятия

| Понятие | Что это |
|---|---|
| **WMSPanel** | облачная панель Softvelum, где хранятся настройки серверов Nimble. NNM-Control пишет туда изменения через WMSPanel API (лимит 15 000 вызовов в сутки на аккаунт) |
| **Собственный API Nimble** | API управления на самом сервере (порт 8082). Отсюда панель берёт состояние, живые потоки и статистику — без расхода лимита WMSPanel |
| **Агент** | служба на сервере для работы с файлами: плейлисты, медиа, логи. Необязателен |
| **Помощник** | служба с правами root на машинах раздачи и шлюзах: пакеты, сертификаты, nginx |
| **Событие** | запись о том, что произошло (`stream.down`, `playlist.deployed`…), в формате `evt/1` |
