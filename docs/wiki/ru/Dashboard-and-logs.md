# Дашборд и логи

[English](../en/Dashboard-and-logs.md) · Русский

## Дашборд

**Панель** — что каждый сервер делает сейчас и что делал раньше.

- Вверху: сколько серверов **отчитываются**, сколько **молчат** (агент не выходил на связь больше 70 с) и
  сколько **без агента**.
- Карточка на сервер: процессор (внимание выше 85%), память (выше 90%), swap (выше 5%), сеть; графики
  процессора, памяти, сети и самых нагруженных потоков.
- **Остаток WMSPanel API** на сегодня: потрачено, лимит, когда сбросится, прогноз до полуночи. Панель
  считает только свои вызовы — реальный остаток может быть меньше.
- **Диапазон** 15 мин … 24 ч, **Настройка дашборда** (какие графики, 1–3 колонки, обновление, сколько
  потоков на сервер) — у каждого пользователя своя.

Данные о машинах дают агенты: нужен агент и включённые **Метрики хоста от агентов** в настройках, иначе
графики пустые.

## Логи

**Логи** — журнал Nimble со всех серверов в одном месте. Смотреть — `streams.view`. Нужно: агент на
сервере и **Сбор логов Nimble** в настройках (включить может тот, у кого `settings.manage`, — прямо со
страницы, кнопкой **Включить**; агенты подхватят примерно за полминуты).

- Собирается `nimble.log` (можно добавить файлы в настройках). Хранилище ограничено (по умолчанию
  512 МБ) — старые записи вытесняются сами. На уровне debug один сервер пишет около 1 ГБ в сутки.
- Фильтры: сервер, диапазон (до **Всё, что хранится**), текст, уровень (E/W/I/V/D), подсистемы.
- **С группировкой** (по умолчанию) — одинаковые сообщения сворачиваются в шаблоны; щелчок — примеры.
- **Хронологически** — строки как есть; **Следить** — обновление каждые 5 с.
- Поиск ограничен 60 000 записей и 8 секундами; если упёрлись — панель скажет сузить диапазон.

### Окна логов

**Окна логов** раскладывают журнал по темам: SRT, RTMP, Transcoder, Playback/HTTP, Pull ingest, DVR, Core,
Other — с числом записей и ошибок. Пустые окна показываются, а не прячутся; всё, что не попало в окна,
— в Other.

### Дашборды логов и ссылки

**Дашборды логов** (`logs.manage`): **Новый дашборд** → **Добавить окно** → колонки 1–4, высота, ширина,
диапазон → **Сохранить изменения**.

**Выдать ссылку (7 дней)** или **(бессрочно)** — для тех, у кого нет входа в панель. Ссылка показывается
один раз; **Отозвать** действует сразу. По ссылке видно только окна этого дашборда. Ключи потоков в ней
скрыты, а адреса IP, названия потоков и тексты ошибок — **нет**: думайте, кому отдаёте.
