# Если что-то не так

[English](../en/Troubleshooting.md) · Русский

## Панель

**Панель не открывается после обновления.** `nnm-control status` и `nnm-control logs backend`. Если при
обновлении не удалось скачать образы, панель осталась на прежней версии — почините сеть и выполните
`sudo systemctl restart nnm-control`.

**Забыли пароль.** Пароль пользователя задаёт администратор на странице **Пользователи**. Учётную запись
суперадмина может править только он сам, и способа восстановить его пароль из панели нет — храните его
в менеджере паролей.

**Потеряли телефон с 2FA.** Войдите резервным кодом. Нет кодов — администратор нажмёт **Сбросить 2FA**
(2FA суперадмина сбрасывает только он сам).

## Серверы

**У сервера нет живого состояния и графиков.** Проверьте **Хост**, порт и токен управления в карточке
сервера и `management_listen_interfaces` в `nimble.conf`: адрес панели должен быть разрешён. На вкладке
графиков **Почему нет данных?** покажет, какой запрос не прошёл.

**Нет вкладок с настройками потоков.** Сервер не привязан к серверу WMSPanel — выберите его в карточке
(список заполняется, когда заданы ключи WMSPanel API).

**Изменение есть в панели, но не на сервере.** WMSPanel доставляет изменения на Nimble циклом примерно
в 30 секунд. Если дольше — проверьте сервер в самой WMSPanel.

**Кончается лимит WMSPanel.** Остаток — на дашборде. Не опрашивайте `GET …/streams` из своих программ
часто — для слежения есть события `stream.up` / `stream.down`, они лимит не тратят.

## Агент

Смотрите сообщение на странице **Агенты** — таблица значений на странице
[Серверы и агенты](Servers-and-agents.md#если-агент-молчит). Чаще всего:

- агент не достаёт до панели по адресу из команды установки — задайте **Внешний адрес этой панели** и
  выдайте команду заново;
- `journalctl -u nnm-agent -n 50` на сервере покажет причину.

## Плейлисты

**Записали, а в эфире ничего не изменилось.**

1. Тот ли файл? По умолчанию панель пишет `server_playlist.json`; если Nimble читает другой — выберите его
   в панели «На сервере». Версии до 1.32.0 предлагали `playlist.json` и `server-playlist.json` — после
   обновления проверьте, не остались ли на сервере такие файлы от прошлых выгрузок.
2. Не остался ли у изменённого блока старый `Id`? Панель обновляет его сама при записи; если файл
   правили руками — поменяйте `Id` (кнопка **Новый Id**).

**Поток сыграл один раз и замолчал.** У блока нет `MaxIterations` (у Nimble по умолчанию — один раз).
Поставьте `0` — бесконечно.

**Файл есть, но не играет.** Nimble Playout играет только MP4 и MP3:
`ffmpeg -i file.mov -c copy -movflags +faststart file.mp4`.

**«Часть файлов на сервере отсутствует».** Загрузите их (**Загрузить файл**) или проверьте путь. Файлы вне
каталога, доступного агенту, помечаются «нельзя проверить», а не «нет».

## API и webhooks

**`401`.** Токен отозван, истёк или запрос пришёл не с разрешённого адреса. Последнее использование
токена видно на странице **API-токены**.

**`412 precondition_failed`.** Объект изменили после вашего чтения — прочитайте `details.current` и
повторите с новым `ETag`.

**Webhooks не приходят.**

- **Webhooks → Доставки** — код ответа и ошибка по каждой попытке.
- «refused» в ошибке — адрес запрещён правилами (loopback, link-local, сама машина панели).
- Подписка выключилась после 50 неудач подряд — почините получателя и **Включить**.
- Ответ `3xx` — перенаправления не выполняются, укажите конечный адрес.

**Приходят дубли.** Это нормально: доставка «хотя бы один раз». Отбрасывайте повторы по `id`.

**`server.*` и `stream.*` не приходят.** Наблюдение включено? (**Webhooks → Наблюдение за серверами и
потоками**.) У сервера настроен собственный API Nimble? Помните, что первый опрос после запуска панели
событий не даёт.
