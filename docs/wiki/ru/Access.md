# Доступ: пользователи, роли, аудит

[English](../en/Access.md) · Русский

## Кто есть кто

| Тип | Что может |
|---|---|
| **Суперадмин** | Всё. Он один, создаётся при первом запуске. Его роль нельзя сменить, учётную запись — удалить; править её может только он сам. Только суперадмин создаёт и удаляет админов и сбрасывает собственную 2FA. |
| **Админ** | Все права. |
| **Своя роль** | Только права своей роли. |

## Пользователи

**Доступ и аудит → Пользователи** (право `users.manage`).

- **Новый пользователь** — логин, пароль, роль. Пароль задавайте не короче 8 символов: эта форма длину
  не проверяет, проверяет только смена пароля в профиле.
- Снять отметку **Активен** — пользователь теряет доступ сразу, на следующем же запросе.
- **Сбросить 2FA** — для того, кто потерял телефон. Действие записывается в аудит.

Вход действует 12 часов (настройка `JWT_TTL` в `/etc/nnm-control/nnm-control.env`). Смена пароля уже
выданные входы не прерывает — чтобы выгнать человека немедленно, снимите **Активен**.

## Роли

**Доступ и аудит → Роли** (право `roles.manage`). Роль — название, описание и набор прав. Для права
`functions.execute` отдельно указывается, какие именно функции роль может запускать. Роль, назначенную
пользователям, удалить нельзя — сначала переназначьте их.

### Права

| Право | Что даёт |
|---|---|
| `servers.view` / `servers.manage` | видеть серверы и их состояние / добавлять, менять, удалять |
| `streams.view` | живые потоки и настройки RTMP; дашборд и логи |
| `sessions.view` / `sessions.manage` | сессии зрителей / отключать зрителей |
| `srt.view` | статистика SRT |
| `republish.view` / `republish.manage` | правила RTMP republish |
| `mpegts.view` | состояние и настройки MPEG-TS |
| `wmsobjects.view` / `wmsobjects.manage` | объекты WMSPanel: UDP/SRT-выходы, MPEG-TS, hot swap, live pull, приложения, транскодеры |
| `playlist.view` / `playlist.manage` | плейлисты Nimble |
| `logs.manage` | дашборды логов и ссылки на них |
| `category.view` / `category.manage` | категории потоков и массовые действия |
| `functions.manage` / `functions.execute` | создавать функции / запускать разрешённые |
| `cdn.view` / `cdn.manage` | сети раздачи, роли узлов, география |
| `control.manage` | перечитать конфиг и сертификаты Nimble, синхронизация с WMSPanel |
| `zabbix.view` | адреса для Zabbix |
| `settings.manage` | системные настройки и ключи WMSPanel API |
| `audit.view` / `audit.manage` | журнал аудита / очистка машинных записей |
| `users.manage` / `roles.manage` | пользователи / роли |

| `webhooks.manage` | подписки webhooks и наблюдение за серверами |

## Профиль

**Система → Профиль** — у каждого свой:

- тема (системная, тёмная, светлая) и язык (EN/RU);
- **Сменить пароль** — нужен текущий; новый не короче 8 символов.

### Двухфакторная аутентификация

1. **Настроить 2FA** — отсканировать QR-код приложением-аутентификатором (или ввести ключ вручную).
2. Ввести **Код подтверждения** → **Включить 2FA**.
3. Панель покажет **10 резервных кодов — один раз**. Каждый срабатывает один раз. Сохраните их и
   нажмите **Я сохранил**.

Дальше при входе панель спросит 6-значный код или резервный код (в течение 5 минут после пароля).
Отключить 2FA — нужны и пароль, и код. «Код не подошёл» чаще всего значит, что на телефоне сбиты часы.

## API-токены и webhooks

Программам — не учётные записи людей, а [API-токены](API.md#токен): у токена свои права, свой список
разрешённых адресов и срок, его можно отозвать, не трогая людей. Рассылка событий — [Webhooks](Webhooks.md).

## Журнал аудита

**Доступ и аудит → Аудит** (право `audit.view`).

- Записывается каждое изменение (просмотры — нет), входы — и удачные, и нет, — действия с 2FA,
  запуски функций. Пароли, токены, ключи в записях скрыты.
- Действия программ записаны как `token:<название>#<id>`.
- Фильтры: **Пользователь** (точное совпадение), **Действие содержит…**, результат. Показывается по
  200 записей; **Загрузить ранние** — дальше.
- Записи хранятся 30 дней.
- **Очистить журнал** (право `audit.manage`) удаляет только машинные записи опроса агентами, действия
  людей — никогда. После удаления журнал сжимается и может быть недоступен несколько минут.

## Zabbix

**Инфраструктура → Zabbix** (право `zabbix.view`) — адреса для HTTP-айтемов Zabbix:

| Адрес | Что отдаёт |
|---|---|
| `GET /api/zabbix/panel` | версия, связь с базой, серверы всего / привязанных, давность синхронизации с WMSPanel (`fleet_sync_age_sec`, -1 — ещё не было), запуски функций за сутки |
| `GET /api/zabbix/app` | время работы, память процесса, связь с базой, число серверов |
| `GET /api/zabbix/system` | нагрузка 1/5/15 мин, ядра, занятая память в %, заполнение корневого диска |

Токен передаётся как `?token=…` или заголовком `X-Zabbix-Token`. На странице показан только
заполнитель `<ZABBIX_TOKEN>`; сам токен — в `/etc/nnm-control/nnm-control.env`, строка `ZABBIX_TOKEN`.
Удобно сделать один HTTP-айтем и зависимые айтемы с JSONPath (`$.load_1m`, `$.mem_used_percent`,
`$.disk_root.used_percent`). Тревога: `fleet_sync_age_sec` больше 900 в режиме WMSPanel — панель давно
не синхронизировалась.
